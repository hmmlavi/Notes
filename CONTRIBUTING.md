# Contributing

1. Open an issue describing the bug or proposed improvement.
2. Keep changes focused and avoid unrelated formatting churn.
3. Run `gradle testDebugUnitTest` and `gradle assembleDebug`.
4. Test note creation, editing, persistence, search, and archive/trash flows.
5. Never commit API keys, signing keys, passwords, or private user data.
6. Describe any platform behavior that could not be tested locally.
